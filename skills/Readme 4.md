# Skills

Canonical specifications for Sprigly's deliverables. Each skill defines:
- What the deliverable looks like
- Research depth and methodology
- Brand voice and visual identity
- Voice checklist

Skills are reference material for:
- Claude Code when implementing or updating workflows
- John when handcrafting deliverables manually
- Future contributors to maintain consistency

Skills are the source of truth. Workflows should produce output that matches the skill — not the other way around.
