It is left in: this sheet is exactly where a client would catch it.
  • The insights copy is what rationaleFor() renders from that post’s evidence, with the supporting line reading out the same object: avgEngagement 69.9 / posts 8, pillarShare 0.2, cadenceBasis {postsPerWeek: 2.24, source:'observed', months: 4}, 31 posts of history (Build A §10).
  • The posting-time options are the PostingTimes contract’s documented example values, presented as “your usual slots”, which is what that named-slot map (launch / morning / evening / wsg / sundayStyle) actually is.

Wiring these actions

  • Write again → POST /api/plan/shape {targetPostId, instruction}. Confirmed in app/src/app/api/plan/shape/route.ts: it 400s without an instruction, gates on the post’s date via gatePostEdit, and enqueues a shape job. It is metered — getUsageForCycle + isRewriteBlocked can return mode:'blocked' with a summary (“You’ve used all N AI changes this month…”). This sheet still has nowhere to render that; it belongs in the prompt field, and it is on the spec’s gap list.
  • Move → date is PATCH /api/posts/:id {date}, which exists; time has no endpoint. Spec gap 1.
  • Delete → DELETE /api/posts/:id (soft) for a committed post; POST /api/plan/draft {op:'drop'} for a planned one, which returns the whole removed row so undo restores it verbatim rather than rebuilding a husk.
  • Copy is navigator.clipboard.writeText — no API at all, which is the point: the client’s job here is to get the words out of Sprigly and into Instagram.
