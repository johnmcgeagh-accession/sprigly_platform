Wiring, and one consequence worth deciding

  • Write again → POST /api/plan/shape {targetPostId, instruction}. The route 400s without an instruction, so a guided rewrite is what the API has always required; the round-1 blind-regenerate button was the mismatch.
  • Cross-month move is a real change, not just a picker. PATCH /api/posts/:id {date} accepts any editable date, and a post already carries its own cycleId, so the write itself works. But the post then belongs to a month it is not planned in: loadCrossMonthPosts surfaces it by date in the other month's feed, the origin cycle's counts drop, and if the destination month has no cycle at all the post lands in the “Outside this month” strip. Allowing it in the picker means the surface has to say where the post went. Flagged rather than assumed.
  • Time has no endpoint at all — spec gap 1, widened this round from read to read-and-write because the picker now edits it.
