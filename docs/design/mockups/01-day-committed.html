Round-3 changes on this page

  • Tab bar, Today, and the Week|Month switcher — the switcher makes Month a peer view rather than an overlay, so there is no ✕ anywhere in the set.
  • No serif. Round 2 set the wordmark and month title in Fraunces, which was never loaded, so both rendered as Georgia — a document face on the one surface that must not read as a document. The wordmark now falls back to the native stack.
  • Format is the icons v2 set, screenshot-tested at 17px before adoption.
  • Copy moved onto the card. A finding from the critique: the client's real end action is getting a caption into Instagram, and round 2 buried it two taps deep. Copy is a per-post action, which is why it sits on the post and not on the FAB — the critique proposed the latter and it was rejected on that ground.
  • The FAB is never inert. On a committed month the mic runs POST /api/plan/agent → runPlanAgentTurn: move / delete / rewrite / add become pending proposals, not applied changes. That route already accepts source:'voice', so gap 8 is the draft route only. On a read-only cycle data.ask refuses, and the FAB is not rendered at all.
  • Panel bottom padding raised to 116px so neither the tab bar nor the FAB can print over card content. In round 2 the FAB sat on top of the evidence sentence — the one line on this surface that must never be occluded.
