Where the content comes from

  • The tally is the real arithmetic the shipped approval card already does: captions for every beat, hooks for reels and carousels, a script per reel. Earl of East’s October is 1 reel, 2 carousels, 7 singles — so 10 / 3 / 1.
  • The honest-consequence copy is the shipped copy, kept verbatim because it was written to correct a lie: an earlier version told clients “after this the dates and formats are set for the month”, which is false — every post stays editable by date until its own date passes.
  • Frame C is constructed, and says so. The template path’s rationale sentence is exactly what rationaleFor() emits for basis: 'template', and “no formatEngagement, no pillarShare” is asserted by test in Build A §9. But no live client has a recorded thin draft — the one thin-data client (sprigly) has zero ig_posts and has never been assembled. The two-beat shape is therefore an illustration of the rule, not a transcript of a month.
  • The second button in Frame C does not exist as a distinct action — it is the same say-something input, promoted for a month that plainly needs it. Noted in the spec rather than implied to be new machinery.
