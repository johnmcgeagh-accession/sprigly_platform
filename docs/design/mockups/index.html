Round 3 — what changed

  • Colour is tokens. Every value reads a --t-* custom property with the same name app/src/lib/theme.ts injects. These files demonstrate the active theme, Teal v1; changing the twelve lines in the stylesheet's THEME block repaints all ten pages, which is the point of showing it this way.
  • The ink rule. White ink requires a ≥700-tier fill; accent-600 is non-text only. Round 3 tried dark ink on accent-600 — it passes at 5.88:1, but read muddy on the device, so round 4 uses the conventional pairing: white on accent-700, 5.47:1, on the selected day, badges, the summary chip, primary buttons, the nav pill and the mic. accent-600 keeps the jobs that carry nothing on top of them.
  • No serif anywhere. Round 2 kept Fraunces for the wordmark and month title; it was never loaded, so both rendered as Georgia. Everything is the native stack now.
  • A floating bottom nav — a segmented pill carrying Day · Month · Tasks with a separate circular microphone beside it. It supersedes both the round-3 tab bar and the header switcher: one place to change view, one place to talk.
  • Icons v2 — clapperboard, stacked squares, framed image — screenshot-tested at 17px before adoption. The clapperboard took three attempts.
  • The mic is its own control in the nav; approval is a labelled pill on the title row.
  • Action rows are three labelled buttons — icon with the label below, Move carrying its date. This is round 3's recorded reversal, exercised.
