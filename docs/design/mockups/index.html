Mobile plan surface — mockups

Static mockups for the redesigned client plan surface: iOS-native, day-focused, mobile-first, in Sprigly’s locked brand system. Spec and wiring: docs/design/mobile-plan-surface.md.

No build step and no external resources — open any file directly. Fraunces and Inter are self-hosted in the app but not embedded here, so display type falls back to Georgia and UI type to the system sans. Judge weight, rhythm and hierarchy, not glyph shapes. All content is real client data; every page ends with a note saying exactly where each figure came from and which pieces are reconstructions.

Week strip, selected day, post cards with format, pillar, time and status. Per-day add slots replace the global button. Earl of East, October 2026.

Reading these

  • Every frame is 390px wide — an iPhone 14/15 logical viewport. Two or three frames sit side by side on a desktop screen; on a narrow screen they stack and the frame drops its rounded shell.
  • Nothing here is interactive. Buttons, sheets and toasts are rendered in the state being reviewed. The only live behaviour anywhere is the <details> expansion in the rollup, which is native HTML.
  • The brand system is reproduced from app/tailwind.config.ts, not re-invented: coral 600 #E8705F / 700 #C4523F / 800 #8A3323 / 100 #FADDD6, brand slate #334155, muted #5C6470, line #8F9296, canvas #F2F3F5. Coral is never used for small text; coral text appears only on coral-100. White on coral-600 appears only at 15px/700.
