<objective>
## Goal
Build `@sprigly/model-client` (AnthropicClient + BedrockClient + factory) and `@sprigly/audit` (AuditLogger writing to DB with cost_pence computation). Both packages are independently testable in Phase 1 — no live API calls required for tests.

## Purpose
`model-client` is the inference abstraction. Every workflow calls it. Switching from Anthropic API (dev) to Bedrock (prod) is a single env var change. `audit` is non-negotiable — every model call must be logged with token counts and cost. Both packages must be solid before workflows can be built.

## Output
- `@sprigly/model-client`: ModelClient interface, AnthropicClient, BedrockClient (eu-west-2 ConverseCommand), `createModelClientFromEnv` factory, factory tests
- `@sprigly/audit`: AuditLogger interface, DrizzleAuditLogger (writes to audit_log), price map, price map tests
</objective>

    **src/types.ts** — Define the core interfaces locally (structurally compatible with engine/types.ts stubs):
    ```typescript
    export interface ModelCompleteParams {
      model: string;
      system?: string;
      messages: Array<{ role: 'user' | 'assistant'; content: string }>;
      maxTokens?: number;
      tools?: AnthropicTool[];  // Anthropic tool format (both clients use same shape)
    }

    export interface AnthropicTool {
      name: string;
      description?: string;
      input_schema: {
        type: 'object';
        properties?: Record<string, unknown>;
        required?: string[];
      };
    }

    export interface ModelCompleteResult {
      content: string;
      inputTokens: number;
      outputTokens: number;
      modelId: string;
      stopReason: string;
    }

    export interface ModelClient {
      complete(params: ModelCompleteParams): Promise<ModelCompleteResult>;
    }
    ```

    **src/anthropic-client.ts** — Implements ModelClient using @anthropic-ai/sdk:
    - Constructor takes `apiKey: string`
    - `complete()`: calls `client.messages.create()` with `model`, `system`, `messages`, `max_tokens` (default 4096), and `tools` if provided
    - Maps response: `content[0].type === 'text' ? content[0].text : ''` for the text content
    - Returns `{ content, inputTokens: usage.input_tokens, outputTokens: usage.output_tokens, modelId: model, stopReason: stop_reason ?? 'end_turn' }`
    - Avoid: storing the Anthropic client at module level — instantiate in constructor

    **src/bedrock-client.ts** — Implements ModelClient using @aws-sdk/client-bedrock-runtime:
    - Uses `ConverseCommand` from `@aws-sdk/client-bedrock-runtime`
    - Constructor takes `region: string` (default 'eu-west-2')
    - `complete()`:
      - Creates `BedrockRuntimeClient({ region })`
      - Maps `messages` to Bedrock ConverseCommand format: `{ role, content: [{ text: content }] }`
      - Maps `tools` to Bedrock tool config format if provided
      - Sends `ConverseCommand({ modelId: params.model, messages, system: params.system ? [{ text: params.system }] : undefined, toolConfig: ..., inferenceConfig: { maxTokens: params.maxTokens ?? 4096 } })`
      - Extracts text from response: `response.output?.message?.content?.[0]?.text ?? ''`
      - Returns `{ content, inputTokens: response.usage?.inputTokens ?? 0, outputTokens: response.usage?.outputTokens ?? 0, modelId: params.model, stopReason: response.stopReason ?? 'end_turn' }`
    - Note: The BedrockRuntimeClient can be instantiated once per constructor call and reused, or per-request. Instantiate in constructor.
    - Avoid: importing BedrockRuntimeClient at module level in a way that requires AWS credentials at import time — the SDK is lazy about credential resolution.

    **src/price-map.ts** — Cost computation in pence (integer, round up):
    Define a price map type and a function:

    ```typescript
    // Prices per 1M tokens in pence. Values are TODO placeholders — update with real rates.
    // Source for rates: https://www.anthropic.com/pricing (convert USD to GBP, then to pence)
    const PRICE_MAP: Record<string, { inputPer1M: number; outputPer1M: number }> = {
      // Anthropic API model IDs
      'claude-opus-4-7': { inputPer1M: 1200, outputPer1M: 6000 },     // TODO: real rates
      'claude-sonnet-4-6': { inputPer1M: 240, outputPer1M: 1200 },    // TODO: real rates
      'claude-haiku-4-5': { inputPer1M: 20, outputPer1M: 100 },       // TODO: real rates
      // Bedrock cross-region inference profile IDs (eu-west-2)
      'eu.anthropic.claude-opus-4-7-20250514-v1:0': { inputPer1M: 1200, outputPer1M: 6000 },    // TODO
      'eu.anthropic.claude-sonnet-4-5-20251001-v1:0': { inputPer1M: 240, outputPer1M: 1200 },   // TODO
    }

    export function computeCostPence(
      modelId: string,
      inputTokens: number,
      outputTokens: number,
    ): number {
      const prices = PRICE_MAP[modelId]
      if (!prices) return 0
      const inputCost = (inputTokens / 1_000_000) * prices.inputPer1M
      const outputCost = (outputTokens / 1_000_000) * prices.outputPer1M
      return Math.ceil(inputCost + outputCost)
    }
    ```

    **src/price-map.test.ts** — Vitest tests (pure function, no DB):
    ```typescript
    import { describe, it, expect } from 'vitest'
    import { computeCostPence } from './price-map.js'

    describe('computeCostPence', () => {
      it('returns 0 for unknown model', () => {
        expect(computeCostPence('unknown-model', 1000, 500)).toBe(0)
      })

      it('returns non-negative integer for claude-sonnet-4-6', () => {
        const result = computeCostPence('claude-sonnet-4-6', 1_000_000, 1_000_000)
        expect(result).toBeGreaterThan(0)
        expect(Number.isInteger(result)).toBe(true)
      })

      it('returns more for opus than sonnet at same token count', () => {
        const opus = computeCostPence('claude-opus-4-7', 1_000_000, 1_000_000)
        const sonnet = computeCostPence('claude-sonnet-4-6', 1_000_000, 1_000_000)
        expect(opus).toBeGreaterThan(sonnet)
      })

      it('scales linearly with token count', () => {
        const single = computeCostPence('claude-sonnet-4-6', 1_000_000, 0)
        const double = computeCostPence('claude-sonnet-4-6', 2_000_000, 0)
        expect(double).toBe(single * 2)
      })
    })
    ```
