<objective>
## Goal
Build `@sprigly/oauth-tokens`: envelope encryption for OAuth tokens using AWS KMS in prod and a static env-key fallback in local dev. Implement `storeTokens` and `getTokens` against the `oauth_connections` table.

## Purpose
OAuth tokens for Gmail and future providers must be encrypted at rest. Envelope encryption means the master key never touches application memory (KMS handles it). The local dev fallback allows development without AWS credentials, with clear logging that non-production encryption is active.

## Output
- `src/types.ts` — OAuthTokenBundle, EncryptionProvider interface
- `src/crypto.ts` — AES-256-GCM encrypt/decrypt (Node crypto, no deps)
- `src/providers.ts` — KmsProvider + LocalDevProvider + `createEncryptionProvider()` factory
- `src/store-tokens.ts` — `storeTokens(db, provider, clientId, oauthProvider, tokens)`
- `src/get-tokens.ts` — `getTokens(db, provider, clientId, oauthProvider)`
- `src/crypto.test.ts` — round-trip encrypt/decrypt tests (no AWS, no DB)
- `src/index.ts` — re-exports
</objective>

    No new dependencies needed — @aws-sdk/client-kms already in package.json. Node `crypto` is built-in.

    **src/types.ts:**
    ```typescript
    export type OAuthProvider = 'gmail' | 'outlook' | 'slack';

    export interface OAuthTokenBundle {
      accessToken: string;
      refreshToken?: string;
      expiresAt?: number;   // unix epoch ms
      scopes: string[];
      emailAddress?: string;
      raw?: Record<string, unknown>;
    }

    export interface EncryptionProvider {
      // Returns plaintext DEK + the encrypted blob to store
      generateDataKey(context: Record<string, string>): Promise<{ plaintext: Buffer; encrypted: string }>;
      // Decrypts the stored blob back to the plaintext DEK
      decryptDataKey(encryptedKey: string, context: Record<string, string>): Promise<Buffer>;
    }
    ```

    **src/crypto.ts** — AES-256-GCM using Node built-in `crypto`:
    - `encrypt(plaintext: Buffer, key: Buffer): string` — returns base64 string of `iv(12) + authTag(16) + ciphertext`
    - `decrypt(encoded: string, key: Buffer): Buffer` — decodes base64, splits iv/authTag/ciphertext, decrypts
    - Use `crypto.randomBytes(12)` for IV, `createCipheriv('aes-256-gcm', key, iv)` / `createDecipheriv`
    - Key must be exactly 32 bytes; throw `Error('Key must be 32 bytes')` if not

    **src/providers.ts** — Two providers + factory:

    *KmsProvider implements EncryptionProvider:*
    - Constructor: `(keyId: string, region: string)`
    - `generateDataKey()`:
      ```typescript
      const kms = new KMSClient({ region: this.region })
      const result = await kms.send(new GenerateDataKeyCommand({
        KeyId: this.keyId,
        KeySpec: 'AES_256',
        EncryptionContext: context,
      }))
      // result.Plaintext is Uint8Array — convert to Buffer
      // result.CiphertextBlob is Uint8Array — base64 encode for storage
      return { plaintext: Buffer.from(result.Plaintext!), encrypted: Buffer.from(result.CiphertextBlob!).toString('base64') }
      ```
    - `decryptDataKey()`:
      ```typescript
      const kms = new KMSClient({ region: this.region })
      const result = await kms.send(new DecryptCommand({
        CiphertextBlob: Buffer.from(encryptedKey, 'base64'),
        EncryptionContext: context,
      }))
      return Buffer.from(result.Plaintext!)
      ```

    *LocalDevProvider implements EncryptionProvider:*
    - Constructor: `(masterKey: Buffer)` — must be 32 bytes
    - `generateDataKey()`:
      - Generate a random 32-byte DEK: `const dek = crypto.randomBytes(32)`
      - Encrypt the DEK with masterKey using `encrypt(dek, masterKey)` from crypto.ts
      - Return `{ plaintext: dek, encrypted: encryptedDEK }`
    - `decryptDataKey()`:
      - Decrypt the stored blob with masterKey using `decrypt(encryptedKey, masterKey)` from crypto.ts
      - Return the plaintext DEK

    *`createEncryptionProvider()` factory:*
    - Check `process.env['AWS_KMS_KEY_ID']` — if set, return `new KmsProvider(keyId, process.env['AWS_REGION'] ?? 'eu-west-2')`
    - Else check `process.env['LOCAL_DEV_ENCRYPTION_KEY']` — if set:
      - `console.warn('[oauth-tokens] Using LOCAL_DEV_ENCRYPTION_KEY — NOT suitable for production')`
      - Parse as base64, validate 32 bytes, return `new LocalDevProvider(Buffer.from(localKey, 'base64'))`
    - Else throw `new Error('oauth-tokens: set AWS_KMS_KEY_ID or LOCAL_DEV_ENCRYPTION_KEY')`

    **src/store-tokens.ts:**
    ```typescript
    import { db as _db, oauthConnections } from '@sprigly/db'
    import { eq, and } from 'drizzle-orm'
    import type { OAuthProvider, OAuthTokenBundle, EncryptionProvider } from './types.js'
    import { encrypt } from './crypto.js'

    type Db = typeof _db

    export async function storeTokens(
      db: Db,
      provider: EncryptionProvider,
      clientId: string,
      oauthProvider: OAuthProvider,
      tokens: OAuthTokenBundle,
    ): Promise<void> {
      const context = { clientId, provider: oauthProvider }
      const { plaintext: dek, encrypted: encryptedDEK } = await provider.generateDataKey(context)
      const encryptedTokens = encrypt(Buffer.from(JSON.stringify(tokens)), dek)

      await db.insert(oauthConnections).values({
        clientId,
        provider: oauthProvider,
        encryptedTokens,
        encryptedDataKey: encryptedDEK,
        scopes: tokens.scopes,
        emailAddress: tokens.emailAddress ?? null,
        status: 'active',
      }).onConflictDoUpdate({
        target: [oauthConnections.clientId, oauthConnections.provider],
        set: {
          encryptedTokens,
          encryptedDataKey: encryptedDEK,
          scopes: tokens.scopes,
          emailAddress: tokens.emailAddress ?? null,
          status: 'active',
          updatedAt: new Date(),
        },
      })
    }
    ```

    Note: `onConflictDoUpdate` requires a unique constraint on (clientId, provider). The oauth_connections table does NOT have this yet — the schema has no composite unique on these two columns. Add a workaround: use `select` first to determine insert vs update, rather than upsert. Change to:
    ```typescript
    const existing = await db.select({ id: oauthConnections.id })
      .from(oauthConnections)
      .where(and(eq(oauthConnections.clientId, clientId), eq(oauthConnections.provider, oauthProvider)))
      .limit(1)

    if (existing.length > 0 && existing[0] !== undefined) {
      await db.update(oauthConnections)
        .set({ encryptedTokens, encryptedDataKey: encryptedDEK, scopes: tokens.scopes, emailAddress: tokens.emailAddress ?? null, status: 'active', updatedAt: new Date() })
        .where(eq(oauthConnections.id, existing[0].id))
    } else {
      await db.insert(oauthConnections).values({
        clientId, provider: oauthProvider, encryptedTokens,
        encryptedDataKey: encryptedDEK, scopes: tokens.scopes,
        emailAddress: tokens.emailAddress ?? null, status: 'active',
      })
    }
    ```

    **src/get-tokens.ts:**
    ```typescript
    export async function getTokens(
      db: Db,
      provider: EncryptionProvider,
      clientId: string,
      oauthProvider: OAuthProvider,
    ): Promise<OAuthTokenBundle | null> {
      const rows = await db.select()
        .from(oauthConnections)
        .where(and(eq(oauthConnections.clientId, clientId), eq(oauthConnections.provider, oauthProvider)))
        .limit(1)

      const row = rows[0]
      if (!row) return null

      const context = { clientId, provider: oauthProvider }
      const dek = await encProvider.decryptDataKey(row.encryptedDataKey, context)
      const plaintext = decrypt(row.encryptedTokens, dek)
      return JSON.parse(plaintext.toString()) as OAuthTokenBundle
    }
    ```
    (Parameter name `encProvider` for the EncryptionProvider to avoid shadowing the import `provider`.)

    **src/crypto.test.ts** — Vitest, no AWS, no DB:
    ```typescript
    import { describe, it, expect } from 'vitest'
    import { randomBytes } from 'node:crypto'
    import { encrypt, decrypt } from './crypto.js'

    describe('AES-256-GCM round-trip', () => {
      it('decrypts to original plaintext', () => {
        const key = randomBytes(32)
        const plaintext = Buffer.from('{"accessToken":"test123"}')
        const encoded = encrypt(plaintext, key)
        const result = decrypt(encoded, key)
        expect(result.toString()).toBe(plaintext.toString())
      })

      it('produces different ciphertext each call (random IV)', () => {
        const key = randomBytes(32)
        const plaintext = Buffer.from('same content')
        expect(encrypt(plaintext, key)).not.toBe(encrypt(plaintext, key))
      })

      it('throws on wrong key', () => {
        const key = randomBytes(32)
        const wrongKey = randomBytes(32)
        const encoded = encrypt(Buffer.from('secret'), key)
        expect(() => decrypt(encoded, wrongKey)).toThrow()
      })

      it('throws if key is not 32 bytes', () => {
        expect(() => encrypt(Buffer.from('x'), randomBytes(16))).toThrow('Key must be 32 bytes')
      })
    })
    ```
