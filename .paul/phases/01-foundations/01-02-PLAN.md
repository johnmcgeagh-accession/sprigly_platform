<objective>
## Goal
Build the complete `@sprigly/db` package: Drizzle schema for all 13 tables, connection client, migration runner, and seed script that bootstraps Sprigly as the first client.

## Purpose
Every other package depends on these types and this client. Getting the schema right now means downstream packages (engine, workflows, audit, oauth-tokens) can import from `@sprigly/db` without schema churn.

## Output
- `src/schema.ts` — 13 Drizzle tables, all relations, all enums
- `src/client.ts` — typed Drizzle + Postgres connection, env-validated via Zod
- `src/migrate.ts` — runs pending migrations via drizzle-kit
- `src/seed.ts` — inserts Sprigly client row + john.mcgeagh@gmail.com admin user row
- `src/index.ts` — re-exports all schema tables, types, and the db client
- `drizzle.config.ts` — drizzle-kit config
- `migrations/` — generated SQL migration from drizzle-kit generate
</objective>

    9. `auditLog` — id, createdAt, updatedAt, clientId (uuid notNull fk→clients), eventId (uuid nullable fk→incomingEvents), workflowRunId (uuid nullable fk→workflowRuns), action (text notNull), modelId (text), inputTokens (integer), outputTokens (integer), costPence (integer), metadata (jsonb default {})

    Use `text()` for all string-enum columns (not pgEnum) — this avoids enum migration pain for early-stage tables. Add TypeScript types for the status values as string unions in the same file.

    Export each table by name (clients, users, clientConfigs, etc.) and export inferred insert/select types as:
    `export type Client = typeof clients.$inferSelect`
    `export type NewClient = typeof clients.$inferInsert`
    (repeat for every table)

    **client.ts** — Use Zod to validate `DATABASE_URL` env var at module load:
    ```
    import { z } from 'zod'
    const env = z.object({ DATABASE_URL: z.string().url() }).parse(process.env)
    ```
    Then create a postgres connection and drizzle instance:
    ```
    import postgres from 'postgres'
    import { drizzle } from 'drizzle-orm/postgres-js'
    import * as schema from './schema'
    const sql = postgres(env.DATABASE_URL)
    export const db = drizzle(sql, { schema })
    ```
    Export `db` and `sql` (for migrate.ts to close the connection).

    Add `zod` to packages/db/package.json dependencies.

    ```
      dbCredentials: { url: process.env.DATABASE_URL! },
    })
    ```

    **migrate.ts** — Runs pending migrations using drizzle's migrate() helper:
    ```
    import { migrate } from 'drizzle-orm/postgres-js/migrator'
    import { db, sql } from './client'
    await migrate(db, { migrationsFolder: './migrations' })
    await sql.end()
    ```
    Import path: `drizzle-orm/postgres-js/migrator`. Top-level await is fine since this is an ESM script.

    **seed.ts** — Idempotent seed: uses `onConflictDoNothing()` so it's safe to re-run:
    ```
    import { db, sql } from './client'
    import { clients, users } from './schema'

    await db.insert(clients).values({
      name: 'Sprigly',
      slug: 'sprigly',
      status: 'active',
      settings: {},
    }).onConflictDoNothing()

    const [sprigly] = await db.select().from(clients).where(eq(clients.slug, 'sprigly'))

    await db.insert(users).values({
      email: 'john.mcgeagh@gmail.com',
      role: 'admin',
      clientId: null,
    }).onConflictDoNothing()

    await sql.end()
    ```
    Import `eq` from `drizzle-orm`.

    **Run drizzle-kit generate** after writing schema.ts:
    ```
    cd engine && pnpm --filter @sprigly/db generate
    ```
    This creates `migrations/0000_*.sql` with all 13 CREATE TABLE statements. Commit the generated file. Do not edit it manually.

    Verify the migration file exists and contains `CREATE TABLE "clients"`.
