<objective>
## Goal
Build `@sprigly/sources` — Gmail email polling with MIME body parsing and idempotent event creation. The GmailPoller fetches unread inbox messages, parses body and headers, writes `incoming_events` rows, and tracks processed messages in `processed_external_ids` to prevent duplicate processing.

## Purpose
This is the intake end of the engine. Nothing flows through until a source produces `incoming_events` rows. The Gmail poller is the first (and for the MVP, only) source — it turns inbound emails into structured engine events that the EventRouter can match and route to workflows. Everything downstream (02-03 through 02-05) depends on this producing well-formed rows.

## Output
- `src/gmail/gmail-parser.ts` — pure MIME/base64url/HTML-strip functions (testable without network)
- `src/gmail/gmail-parser.test.ts` — unit tests for all parser functions
- `src/gmail/gmail-client.ts` — `GmailApiClient` wrapping `googleapis`, with automatic token refresh
- `src/gmail/gmail-poller.ts` — `GmailPoller` orchestration: tokens → poll → parse → DB writes
- `src/index.ts` — re-exports replacing `export {}` stub
- `package.json` — add `googleapis`, `drizzle-orm`
- `vitest.config.ts` — dummy `DATABASE_URL` for unit test isolation

    **engine/packages/sources/src/gmail/gmail-parser.ts:**

    All functions are pure — no imports from @sprigly/db or googleapis classes (only types).

    Import type `gmail_v1` from `'googleapis'`:
    ```typescript
    import type { gmail_v1 } from 'googleapis';
    ```

    Functions to implement:

    `export function decodeBase64Url(encoded: string): string`
    - Gmail encodes body parts as base64url (uses `-` for `+`, `_` for `/`, no padding)
    - Use `Buffer.from(encoded, 'base64url').toString('utf-8')`

    `export function stripHtml(html: string): string`
    - Remove all HTML tags: `.replace(/<[^>]+>/g, ' ')`
    - Decode common HTML entities: `&amp;` → `&`, `&lt;` → `<`, `&gt;` → `>`, `&nbsp;` → ` `, `&quot;` → `"`
    - Collapse whitespace: `.replace(/\s+/g, ' ').trim()`

    `export function getHeader(headers: gmail_v1.Schema$MessagePartHeader[], name: string): string`
    - Case-insensitive lookup by `header.name`
    - Return `header.value ?? ''` or `''` if not found

    `export function extractTextFromParts(part: gmail_v1.Schema$MessagePart): string`
    - If `part.mimeType === 'text/plain'` and `part.body?.data` exists: return `decodeBase64Url(part.body.data)`
    - If `part.parts` array exists: recurse into each subpart, return first non-empty text/plain result; if none found, recurse again for text/html and return `stripHtml(decoded)` as fallback
    - If `part.mimeType === 'text/html'` and `part.body?.data` exists and no text/plain found: return `stripHtml(decodeBase64Url(part.body.data))`
    - Return `''` if nothing found

    `export function extractMessageText(message: gmail_v1.Schema$Message): string`
    - If `message.payload` is undefined: return `''`
    - If `message.payload.body?.data` exists (simple non-multipart message): return `decodeBase64Url(message.payload.body.data)`
    - Otherwise: return `extractTextFromParts(message.payload)`

    `export function parseReceivedAt(message: gmail_v1.Schema$Message): Date`
    - Use `message.internalDate` (milliseconds since epoch as string)
    - Return `new Date(Number(message.internalDate))` or `new Date()` as fallback

    **engine/packages/sources/src/gmail/gmail-client.ts:**

    Imports: `google, gmail_v1` from `'googleapis'`; `OAuthTokenBundle` from `'@sprigly/oauth-tokens'`.

    ```typescript
    export class GmailApiClient {
      private gmail: gmail_v1.Gmail;

      constructor(
        googleClientId: string,
        googleClientSecret: string,
        private tokens: OAuthTokenBundle,
        private onTokensRefreshed: (tokens: OAuthTokenBundle) => Promise<void>,
      ) {
        const auth = new google.auth.OAuth2(googleClientId, googleClientSecret);
        auth.setCredentials({
          access_token: tokens.accessToken,
          refresh_token: tokens.refreshToken,
          expiry_date: tokens.expiresAt,
        });
        auth.on('tokens', (newTokens) => {
          void onTokensRefreshed({
            accessToken: newTokens.access_token ?? tokens.accessToken,
            refreshToken: newTokens.refresh_token ?? tokens.refreshToken,
            expiresAt: newTokens.expiry_date ?? tokens.expiresAt,
            scopes: tokens.scopes,
            emailAddress: tokens.emailAddress,
          });
        });
        this.gmail = google.gmail({ version: 'v1', auth });
      }

      async listMessageIds(maxResults = 50): Promise<string[]> {
        const res = await this.gmail.users.messages.list({
          userId: 'me',
          q: 'in:inbox is:unread',
          maxResults,
        });
        return (res.data.messages ?? []).map((m) => m.id ?? '').filter(Boolean);
      }

      async getMessage(messageId: string): Promise<gmail_v1.Schema$Message> {
        const res = await this.gmail.users.messages.get({
          userId: 'me',
          id: messageId,
          format: 'full',
        });
        return res.data;
      }

      async markAsRead(messageId: string): Promise<void> {
        await this.gmail.users.messages.modify({
          userId: 'me',
          id: messageId,
          requestBody: { removeLabelIds: ['UNREAD'] },
        });
      }
    }
    ```

    Note on the `tokens` event: `auth.on('tokens', ...)` fires when googleapis auto-refreshes. The callback is `void`-wrapped because the event emitter cannot await async callbacks — token storage errors should not crash the polling process.

    exactOptionalPropertyTypes: `OAuthTokenBundle.refreshToken` and `expiresAt` are optional. Use spread conditional when building the refreshed bundle:
    ```typescript
    const refreshed: OAuthTokenBundle = {
      accessToken: newTokens.access_token ?? tokens.accessToken,
      scopes: tokens.scopes,
      ...(newTokens.refresh_token !== undefined && { refreshToken: newTokens.refresh_token }),
      ...(tokens.refreshToken !== undefined && newTokens.refresh_token === undefined && { refreshToken: tokens.refreshToken }),
      ...(newTokens.expiry_date !== null && newTokens.expiry_date !== undefined && { expiresAt: newTokens.expiry_date }),
      ...(tokens.emailAddress !== undefined && { emailAddress: tokens.emailAddress }),
    };
    void onTokensRefreshed(refreshed);
    ```

    **engine/packages/sources/src/gmail/gmail-poller.ts:**

    Imports:
    - `db as _db, incomingEvents, processedExternalIds` from `'@sprigly/db'`
    - `eq, and` from `'drizzle-orm'`
    - `getTokens, storeTokens, EncryptionProvider` from `'@sprigly/oauth-tokens'`
    - `GmailApiClient` from `'./gmail-client.js'`
    - `extractMessageText, getHeader, parseReceivedAt` from `'./gmail-parser.js'`

    Type alias: `type Db = typeof _db`

    ```typescript
    export class GmailPoller {
      constructor(
        private db: Db,
        private encProvider: EncryptionProvider,
        private googleClientId: string,
        private googleClientSecret: string,
      ) {}

      async poll(clientId: string): Promise<number> {
        const tokens = await getTokens(this.db, this.encProvider, clientId, 'gmail');
        if (tokens === null) return 0;

        const client = new GmailApiClient(
          this.googleClientId,
          this.googleClientSecret,
          tokens,
          (refreshed) => storeTokens(this.db, this.encProvider, clientId, 'gmail', refreshed),
        );

        const messageIds = await client.listMessageIds();
        let count = 0;

        for (const messageId of messageIds) {
          // Idempotency check
          const existing = await this.db
            .select({ id: processedExternalIds.id })
            .from(processedExternalIds)
            .where(
              and(
                eq(processedExternalIds.clientId, clientId),
                eq(processedExternalIds.source, 'gmail'),
                eq(processedExternalIds.externalId, messageId),
              ),
            )
            .limit(1);

          if (existing[0] !== undefined) {
            await client.markAsRead(messageId);
            continue;
          }

          const message = await client.getMessage(messageId);
          const headers = message.payload?.headers ?? [];
          const text = extractMessageText(message);
          const subject = getHeader(headers, 'Subject');
          const from = getHeader(headers, 'From');
          const to = getHeader(headers, 'To');
          const date = getHeader(headers, 'Date');
          const receivedAt = parseReceivedAt(message);

          // Record as processed first (idempotency guard before DB write)
          await this.db.insert(processedExternalIds).values({
            clientId,
            source: 'gmail',
            externalId: messageId,
            processedAt: new Date(),
          });

          // Insert incoming event
          await this.db.insert(incomingEvents).values({
            clientId,
            source: 'email',
            sourceMetadata: {
              messageId,
              threadId: message.threadId ?? '',
              from,
              to,
              subject,
              date,
            },
            content: {
              text,
              structured: { subject },
            },
            receivedAt,
            status: 'received',
            externalId: messageId,
          });

          await client.markAsRead(messageId);
          count++;
        }

        return count;
      }
    }
    ```

    Order of DB writes (crash-safe reasoning):
    1. `processedExternalIds` inserted first — if crash after this but before `incomingEvents`, next poll sees it as already processed and skips (event lost but no duplicate)
    2. `incomingEvents` inserted second
    3. `markAsRead` last — cleanup only; if it fails, the message shows as unread but idempotency guard prevents reprocessing
