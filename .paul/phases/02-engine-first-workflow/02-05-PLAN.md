<objective>
## Goal
Implement `apps/worker` — the long-running Node.js service that polls Gmail, enqueues events to BullMQ, processes them through the engine (router → runner → dispatcher), and a one-time OAuth setup script that stores encrypted Gmail tokens.

## Purpose
This is the process that makes the engine run end-to-end. Everything built in 02-01 through 02-04 is wired together here: GmailPoller feeds events to BullMQ, the consumer routes each event, WorkflowRunner executes the blog-post workflow, and DestinationDispatcher saves the post and sends the notification email. After this plan, sending `Blog: [topic]` to the connected Gmail account produces a blog post in the DB and a notification reply.

## Output
- `src/env.ts` — Zod validation for worker-owned env vars (REDIS_URL, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, POLL_INTERVAL_MS)
- `src/poller.ts` — `pollAllClients()`: queries active Gmail connections, polls each, enqueues received event IDs
- `src/consumer.ts` — `createConsumer()`: BullMQ Worker that routes, runs, and dispatches each event
- `src/index.ts` — replaces stub: bootstraps all engine pieces, starts poller interval and BullMQ worker, SIGTERM handler
- `src/setup-gmail-oauth.ts` — one-time CLI script: HTTP callback capture, token exchange, storeTokens
- `package.json` — adds bullmq, zod, googleapis, @sprigly/model-client, @sprigly/oauth-tokens, @sprigly/prompts; adds "setup-gmail" script
</objective>

    Imports:
    - `db as _db, incomingEvents, workflowRuns` from `'@sprigly/db'`
    - `type { IncomingEvent as DbIncomingEvent }` from `'@sprigly/db'`
    - `eq, and, desc` from `'drizzle-orm'`

    - `type { EventRouter, WorkflowRunner, DestinationDispatcher }` from `'@sprigly/engine'`
    - `type { WorkflowRegistry }` from `'@sprigly/engine'`
    - `type { SourceType, IncomingEvent }` from `'@sprigly/engine'`
    - `type { Logger }` from `'pino'`

    ```typescript
    type Db = typeof _db;
    ```

    Private helper `toEngineEvent(row: DbIncomingEvent): IncomingEvent`:
    Replicates the conversion from workflow-runner.ts (can't export from engine without changes):
    ```
    - content = row.content as { text?: string; structured?: Record<string, unknown> }
    - structured = content['structured'] as Record<string, unknown> | undefined
    - Return IncomingEvent with:
        id, clientId, source (cast to SourceType), sourceMetadata, receivedAt,
        content: { text: content['text'] ?? '', ...(structured !== undefined && { structured }) },
        reply: { channel: row.source as SourceType, data: row.sourceMetadata }
    ```

    Exported function `createConsumer(db, router, registry, runner, dispatcher, logger, redisUrl)`:
    - Returns a BullMQ `Worker` (named `BullWorker` to avoid collision with `Worker` global)
    - Queue name: `'incoming-events'`
    - Connection: `{ url: redisUrl }` passed as `connection` option
    - Concurrency: `1`

    Processor function for each job (job data: `{ eventId: string; clientId: string }`):
    1. Destructure `{ eventId }` from `job.data`
    2. Fetch event: `db.select().from(incomingEvents).where(eq(incomingEvents.id, eventId)).limit(1)`
    3. If no row: `logger.warn({ eventId }, 'event not found'); return`
    4. `const event = toEngineEvent(dbEvent)`
    5. `const rules = await router.route(event)`
    6. If `rules.length === 0`:
       - `await db.update(incomingEvents).set({ status: 'ignored' }).where(eq(incomingEvents.id, eventId))`
       - `logger.info({ eventId }, 'no matching rules'); return`
    7. For each `rule` of `rules`:
       a. `const output = await runner.run(rule, eventId)` — returns `null` if parseInput null
       b. If `output === null`: continue
       c. Fetch runId: query `workflowRuns` WHERE `eventId = eventId AND workflowId = rule.workflowId`
          ORDER BY `startedAt DESC` LIMIT 1 → `runId = row?.id ?? ''`
       d. `await dispatcher.dispatch(output, event, rule, runId)`
       e. `logger.info({ eventId, workflowId: rule.workflowId }, 'dispatched')`
    8. Wrap the entire processor in try/catch: `logger.error({ eventId, err: String(err) }, 'job failed')`; rethrow (BullMQ marks job as failed)

    One-time CLI script: generates an OAuth2 auth URL, starts a localhost HTTP callback server
    to capture the code automatically, exchanges for tokens, stores them encrypted.

    Usage: `tsx src/setup-gmail-oauth.ts <client-slug>`

    Imports:
    - `http` from `'node:http'`
    - `google` from `'googleapis'`
    - `db` from `'@sprigly/db'`
    - `{ clients }` from `'@sprigly/db'`
    - `{ eq }` from `'drizzle-orm'`
    - `{ storeTokens, createEncryptionProvider }` from `'@sprigly/oauth-tokens'`
    - `env` from `'./env.js'`

    Constants:
    ```typescript
    const REDIRECT_URI = 'http://localhost:3000';
    const SCOPES = [
      'https://www.googleapis.com/auth/gmail.modify',
      'https://www.googleapis.com/auth/gmail.send',
    ];
    ```

    Implementation (top-level await, script exits when done):
    1. `const slug = process.argv[2]`
       If undefined: `console.error('Usage: tsx src/setup-gmail-oauth.ts <client-slug>'); process.exit(1)`

    2. Look up client in DB:
       ```
       const rows = await db.select({ id: clients.id }).from(clients).where(eq(clients.slug, slug)).limit(1);
       const client = rows[0];
       if (!client) { console.error(`Client not found: ${slug}`); process.exit(1); }
       ```

    3. Build OAuth2 client:
       ```
       const auth = new google.auth.OAuth2(env.GOOGLE_CLIENT_ID, env.GOOGLE_CLIENT_SECRET, REDIRECT_URI);
       ```

    4. Generate auth URL:
       ```
       const authUrl = auth.generateAuthUrl({
         access_type: 'offline',
         prompt: 'consent',
         scope: SCOPES,
       });
       console.log('\nOpen this URL in your browser:\n');
       console.log(authUrl);
       console.log('\nWaiting for OAuth callback on http://localhost:3000 ...\n');
       ```

    5. Start localhost HTTP server to capture code:
       ```typescript
       const code = await new Promise<string>((resolve, reject) => {
         const server = http.createServer((req, res) => {
           const url = new URL(req.url ?? '/', 'http://localhost:3000');
           const code = url.searchParams.get('code');
           if (code) {
             res.writeHead(200, { 'Content-Type': 'text/html' });
             res.end('<h1>Authorization successful. You can close this tab.</h1>');
             server.close();
             resolve(code);
           } else {
             res.writeHead(400, { 'Content-Type': 'text/plain' });
             res.end('Missing code parameter');
             server.close();
             reject(new Error('OAuth callback missing code parameter'));
           }
         });
         server.listen(3000);
       });
       ```

    6. Exchange code for tokens:
       ```
       const { tokens } = await auth.getToken(code);
       auth.setCredentials(tokens);
       ```

    7. Fetch user email via userinfo:
       ```
       const oauth2 = google.oauth2({ version: 'v2', auth });
       const userInfo = await oauth2.userinfo.get();
       const emailAddress = userInfo.data.email ?? undefined;
       ```

    8. Build OAuthTokenBundle and store:
       ```typescript
       const encProvider = createEncryptionProvider();
       const bundle: OAuthTokenBundle = {
         accessToken: tokens.access_token ?? '',
         scopes: SCOPES,
         ...(typeof tokens.refresh_token === 'string' && { refreshToken: tokens.refresh_token }),
         ...(tokens.expiry_date != null && { expiresAt: tokens.expiry_date }),
         ...(emailAddress !== undefined && { emailAddress }),
       };
       await storeTokens(db, encProvider, client.id, 'gmail', bundle);
       ```

    9. Print success and exit:
       ```
       console.log(`\nTokens stored for client '${slug}' (${emailAddress ?? 'email unknown'})`);
       console.log('oauth_connections row created. Worker is ready to poll Gmail.');
       process.exit(0);
       ```

    Import `type { OAuthTokenBundle }` from `'@sprigly/oauth-tokens'` for the bundle type.

    Note: `storeTokens` from @sprigly/oauth-tokens does an upsert-by-select pattern
    (no composite unique on oauth_connections). If a row already exists for this clientId+provider,
    the existing connection will remain (storeTokens inserts, it doesn't update — check if a
    select-first update-if-exists pattern is needed).

    Actually — storeTokens always inserts. For the setup script, this is fine on first run.
    On subsequent runs a duplicate row will be inserted. Add a note in the console output:
    "If re-running, manually delete the existing oauth_connections row first."
