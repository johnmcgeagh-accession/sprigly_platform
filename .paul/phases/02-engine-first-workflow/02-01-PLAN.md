## Goal
Implement the engine orchestration layer: EventRouter (DB query + condition matching), WorkflowRegistry (Map wrapper), WorkflowRunner (run record lifecycle), DestinationDispatcher (delivery + approvals), and DbPromptResolver (DB-backed prompt lookup). Replace all `// TODO` stubs with real implementations.

## Purpose
This is the connective tissue of the engine. Sources produce events; the EventRouter finds matching routing rules; the WorkflowRunner builds context and executes the workflow; the DestinationDispatcher delivers results. Without this layer, there is no engine — just isolated packages. Plans 02-02 through 02-05 plug implementations (Gmail source, blog workflow, destinations, worker) into the contracts defined and wired here.

    ```typescript
    type Db = typeof _db;

    export class DbPromptResolver {
      constructor(private db: Db) {}

      async resolve(clientId: string, workflowId: string, stepName: string): Promise<string> {
        // 1. Try client-specific template first
        const clientRows = await this.db
          .select()
          .from(promptTemplates)
          .where(
            and(
              eq(promptTemplates.clientId, clientId),
              eq(promptTemplates.workflowId, workflowId),
              eq(promptTemplates.stepName, stepName),
            )
          )
          .orderBy(desc(promptTemplates.version))
          .limit(1);

        if (clientRows[0] !== undefined) {
          return clientRows[0].promptText;
        }

        // 2. Fall back to global template (clientId IS NULL)
        const globalRows = await this.db
          .select()
          .from(promptTemplates)
          .where(
            and(
              isNull(promptTemplates.clientId),
              eq(promptTemplates.workflowId, workflowId),
              eq(promptTemplates.stepName, stepName),
            )
          )
          .orderBy(desc(promptTemplates.version))
          .limit(1);

        if (globalRows[0] !== undefined) {
          return globalRows[0].promptText;
        }

        throw new Error(
          `No prompt template found for workflow=${workflowId} step=${stepName} (clientId=${clientId})`
        );
      }
    }
    ```

    **engine/packages/engine/src/event-router.ts:**

    Imports: `db as _db, routingRules` from `@sprigly/db`; `eq, and, desc` from `drizzle-orm`; engine types from `./types.js`.

    Export a pure condition evaluator (for unit testing without DB):
    ```typescript
    export function extractField(event: IncomingEvent, field: string): string {
      // 'body' → event.content.text
      // all other fields → String(event.sourceMetadata[field] ?? '')
      if (field === 'body') return event.content.text;
      return String(event.sourceMetadata[field] ?? '');
    }

    export function evaluateCondition(condition: MatchCondition, event: IncomingEvent): boolean {
      const raw = extractField(event, condition.field);
      const val = condition.caseSensitive ? raw : raw.toLowerCase();
      const target = condition.caseSensitive ? condition.value : condition.value.toLowerCase();

      switch (condition.op) {
        case 'equals': return val === target;
        case 'contains': return val.includes(target);
        case 'startsWith': return val.startsWith(target);
        case 'endsWith': return val.endsWith(target);
        case 'regex': return new RegExp(condition.value, condition.caseSensitive ? '' : 'i').test(raw);
      }
    }

    export function evaluateConditions(conditions: MatchCondition[], event: IncomingEvent): boolean {
      return conditions.every(c => evaluateCondition(c, event));
    }
    ```

    `EventRouter` class:
    ```typescript
    export class EventRouter {
      constructor(private db: Db) {}

      async route(event: IncomingEvent): Promise<RoutingRule[]> {
        const rows = await this.db
          .select()
          .from(routingRules)
          .where(
            and(
              eq(routingRules.clientId, event.clientId),
              eq(routingRules.source, event.source),
              eq(routingRules.enabled, true),
            )
          )
          .orderBy(desc(routingRules.priority));

        const engineRules = rows.map(toEngineRule);
        return engineRules.filter(rule => evaluateConditions(rule.match.conditions, event));
      }
    }
    ```

    **engine/packages/engine/src/workflow-runner.ts:**

    Imports: `db as _db, workflowRuns, incomingEvents, clientConfigs, IncomingEvent as DbIncomingEvent` from `@sprigly/db`; `eq` from `drizzle-orm`; engine types from `./types.js`; `WorkflowRegistry` from `./workflow-registry.js`.

    Type alias: `type Db = typeof _db`

    Private `toEngineEvent(row: DbIncomingEvent): IncomingEvent`:
    - Cast `row.content` as `{ text?: string; structured?: Record<string, unknown> }`
    - Build the engine IncomingEvent shape
    - `reply: { channel: row.source as SourceType, data: row.sourceMetadata }`

    `WorkflowRunner` class, constructor takes `(db: Db, registry: WorkflowRegistry, model: ModelClient, audit: AuditLogger, prompts: PromptResolver)`.

    `async run(rule: RoutingRule, dbEventId: string): Promise<unknown>`:
    1. Fetch DB event row: `db.select().from(incomingEvents).where(eq(incomingEvents.id, dbEventId)).limit(1)` → throw if not found
    2. Insert `workflow_runs` row: `{ eventId, clientId: dbEvent.clientId, workflowId: rule.workflowId, status: 'running', startedAt: new Date() }`; save the inserted row's `id` as `runId`
    3. Update `incoming_events` status to `'running'` where `id = dbEventId`
    4. Get workflow from registry: `registry.get(rule.workflowId)` → if undefined: update run to 'failed' (error: 'workflow not registered'), update event to 'failed', throw
    5. Convert DB event to engine event: `const event = toEngineEvent(dbEvent)`
    6. Fetch clientConfig row (if `rule.clientConfigId` is non-empty): `db.select().from(clientConfigs).where(eq(clientConfigs.id, rule.clientConfigId)).limit(1)` — else use default stub `{ id: '', clientId: event.clientId, brandVoice: '', signature: '', authorName: '', settings: {} }`
    7. Build `WorkflowContext`: `{ clientId: event.clientId, clientConfig, model, audit, prompts, eventId: dbEventId, runId }`
    8. `const input = workflow.parseInput(event)` — if null: update run to 'completed' (no output), update event to 'ignored', return null
    9. `const output = await workflow.run(input, ctx)` wrapped in try/catch:
       - On success: update run `{ status: 'completed', endedAt: new Date(), output: output as Record<string, unknown> }`, update event status to `'completed'`
       - On error: update run `{ status: 'failed', endedAt: new Date(), error: String(err) }`, update event to `'failed'`, rethrow
    10. Return `output`

    `async dispatch(output: unknown, event: IncomingEvent, rule: RoutingRule, runId: string): Promise<void>`:
    - For each `config` in `rule.destinations`:
      - Get destination: `this.destinations.get(config.destinationId)` → if not found: `console.error(...)` and continue
      - If `destination.requiresApproval(config)`:
        - Insert `approvals` row: `{ workflowRunId: runId, status: 'pending', outputSnapshot: output as Record<string, unknown> }`
        - continue (do NOT call deliver)
      - Else: `await destination.deliver(output, event, config)` — catch errors: `console.error(...)` continue
