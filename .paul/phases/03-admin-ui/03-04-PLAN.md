  <action>
    **`approvals/actions.ts`** — top-level `'use server'`:

    ```typescript
    export async function approveRun(formData: FormData): Promise<void> {
      const approvalId = formData.get('approvalId') as string;
      await db.update(approvals).set({ status: 'approved', decidedAt: new Date() }).where(eq(approvals.id, approvalId));
      revalidatePath('/admin/approvals');
    }

    export async function rejectRun(formData: FormData): Promise<void> {
      const approvalId = formData.get('approvalId') as string;
      await db.update(approvals).set({ status: 'rejected', decidedAt: new Date() }).where(eq(approvals.id, approvalId));
      revalidatePath('/admin/approvals');
    }
    ```
    Imports: `db, approvals` from `@sprigly/db`; `eq` from `drizzle-orm`; `revalidatePath` from `next/cache`.

    ---

    **Approvals list** (`/admin/approvals/page.tsx`):
    - Server Component; query pending approvals joined to workflowRuns + clients:
      ```typescript
      db.select({
        approvalId: approvals.id,
        status: approvals.status,
        outputSnapshot: approvals.outputSnapshot,
        createdAt: approvals.createdAt,
        workflowRunId: approvals.workflowRunId,
        workflowId: workflowRuns.workflowId,
        runStatus: workflowRuns.status,
        clientName: clients.name,
      })
      .from(approvals)
      .innerJoin(workflowRuns, eq(approvals.workflowRunId, workflowRuns.id))
      .innerJoin(clients, eq(workflowRuns.clientId, clients.id))
      .where(eq(approvals.status, 'pending'))
      .orderBy(desc(approvals.createdAt))
      ```
    - For each approval, render a card (not table — cards allow outputSnapshot preview):
      - Card header: client name, workflowId (monospace), run status badge, created timestamp
      - outputSnapshot preview: `<pre>` with `JSON.stringify(row.outputSnapshot, null, 2)`, max-h-32, overflow-auto, truncated display
      - Actions: two `<form>` elements using `approveRun` and `rejectRun`:
        - Both have `<input type="hidden" name="approvalId" value={row.approvalId} />`
        - Approve: green button, Reject: red outline button
    - Empty state: "No pending approvals." (with green check visual or just text)
    - Imports: `db, approvals, workflowRuns, clients` from `@sprigly/db`; `eq, desc` from `drizzle-orm`; `approveRun, rejectRun` from `./actions`

    ---

    **Audit log** (`/admin/audit/page.tsx`):
    - Server Component; query 100 most recent entries joined to clients:
      ```typescript
      db.select({
        id: auditLog.id,
        action: auditLog.action,
        modelId: auditLog.modelId,
        inputTokens: auditLog.inputTokens,
        outputTokens: auditLog.outputTokens,
        costPence: auditLog.costPence,

      })
      .from(auditLog)
      .innerJoin(clients, eq(auditLog.clientId, clients.id))
      .orderBy(desc(auditLog.createdAt))
      ```

    - Table columns: Action (monospace), Model (monospace, or "—"), Tokens In, Tokens Out, Cost, Client, Timestamp
    - Cost display helper: `costPence != null ? \`£\${(costPence / 100).toFixed(2)}\` : '—'`
    - Tokens display: `entry.inputTokens?.toLocaleString() ?? '—'`
    - Empty state: "No audit entries yet."
    - Imports: `db, auditLog, clients` from `@sprigly/db`; `eq, desc` from `drizzle-orm`
