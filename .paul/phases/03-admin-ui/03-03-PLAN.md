<objective>
## Goal
Prompt template editor with version history — list latest versions, view/edit any version, save edits as a new version (immutable history).

## Purpose
Prompts drive all AI output quality. Operators need to iterate on prompts without losing what worked before. The immutable version pattern ensures every prompt change is traceable and reversible.

## Output
Three files: list page, detail/edit page, server action. No schema changes — version history is already modelled in `prompt_templates` (unique index on clientId + workflowId + stepName + version).
</objective>

    Server Component. Fetches all prompt templates (all versions), deduplicates to latest version per (clientId, workflowId, stepName) in JS, groups by workflowId for display.

    **Query:**
    ```typescript
    const all = await db
      .select({
        id: promptTemplates.id,
        clientId: promptTemplates.clientId,
        workflowId: promptTemplates.workflowId,
        stepName: promptTemplates.stepName,
        version: promptTemplates.version,
        clientName: clients.name,
      })
      .from(promptTemplates)
      .leftJoin(clients, eq(promptTemplates.clientId, clients.id))
      .orderBy(promptTemplates.workflowId, promptTemplates.stepName, desc(promptTemplates.version));
    ```

    **Deduplication (latest version per combo):**
    ```typescript
    const seen = new Set<string>();
    const latest = all.filter((t) => {
      const key = `${t.clientId ?? 'global'}-${t.workflowId}-${t.stepName}`;
      if (seen.has(key)) return false;
      seen.add(key);
      return true;
    });
    ```

    **Grouping by workflowId:**
    ```typescript
    const grouped = latest.reduce<Record<string, typeof latest>>((acc, t) => {
      (acc[t.workflowId] ??= []).push(t);
      return acc;
    }, {});
    ```

    **Display:** For each workflowId group, render a section heading (workflowId monospace) and a table with columns: Step, Version, Client, link "View →" to `/admin/prompts/{id}`.

    Use `leftJoin` so global templates (clientId=null) still appear — show `t.clientName ?? 'global'` for the client column.

    **`actions.ts`** — top-level `'use server'`:

    ```
    saveNewVersion(formData: FormData): Promise<void>
    ```
    - Read: `templateId` (UUID of the row being edited), `promptText`
    - Fetch source row: `db.select().from(promptTemplates).where(eq(promptTemplates.id, templateId)).limit(1)` — throw if not found
    - Determine clientId condition for the version query:
      ```typescript
      const clientCondition = source.clientId
        ? eq(promptTemplates.clientId, source.clientId)
        : isNull(promptTemplates.clientId);
      ```
    - Find max version:
      ```typescript
      const result = await db
        .select({ maxVersion: sql<number>`cast(max(version) as int)` })
        .from(promptTemplates)
        .where(and(clientCondition, eq(promptTemplates.workflowId, source.workflowId), eq(promptTemplates.stepName, source.stepName)));
      const newVersion = (result[0]?.maxVersion ?? 0) + 1;
      ```
    - Insert new row:
      ```typescript
      const [inserted] = await db.insert(promptTemplates).values({
        clientId: source.clientId,
        workflowId: source.workflowId,
        stepName: source.stepName,
        promptText,
        version: newVersion,
      }).returning({ id: promptTemplates.id });
      ```
    - `revalidatePath('/admin/prompts')`
    - `redirect(\`/admin/prompts/\${inserted!.id}\`)`

    Imports: `db, promptTemplates` from `@sprigly/db`; `eq, and, isNull, sql` from `drizzle-orm`; `revalidatePath` from `next/cache`; `redirect` from `next/navigation`.
